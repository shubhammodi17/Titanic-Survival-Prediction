# Titanic-Survival-Prediction

## Objective
The objective of this project is to predict whether a passenger survived the Titanic disaster using Machine Learning.

## Features Used
- Pclass
- Sex
- Age
- SibSp
- Parch
- Fare
- Embarked

## Data Preprocessing
- Missing numerical values handled using median imputation.
- Missing categorical values handled using most frequent imputation.
- One-Hot Encoding used for categorical features.
- StandardScaler applied to numerical features.

## Model Used
Logistic Regression

## Evaluation Metrics
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion Matrix

## Conclusion
The Logistic Regression model provides a strong baseline for binary classification problems like Titanic survival prediction.
